# Vending Machine 解説

## 問題概要
自動販売機シミュレータ。`f`（flag）は選択肢から弾かれるが、コードのバグを突いて取り出す。

## コード解説

```python
self.stock = 'a'*30 + 'b'*60 + 'c'*20 + 'd'*50 + 'e'*40 + 'f'
```
在庫は文字列。末尾に `f`（flag）が1個ある。

```python
if mark not in ['a', 'b', 'c', 'd', 'e']:
    print("Invalid choice.")
    return
```
`f` は直接選べない。

```python
loc = self.stock.find(mark)   # 位置を探す
stock_list = list(self.stock)
item = stock_list.pop(loc)    # その位置を取り出して削除
```
- `find`: 文字の最初の位置を返す。**見つからないと `-1` を返す**。
- `pop`: 指定位置の要素を取り出して削除。**`pop(-1)` は末尾を消す**。

```python
if item == 'f':
    print(f"Flag:", FLAG)
```
取り出した文字が `f` ならフラグ表示。

## 脆弱性
`find` が失敗した時の `-1` を、そのまま `pop` に渡している。

## 攻略手順
1. ある文字（例: `e`）を在庫が尽きるまで買う（`e` は40個）。
2. さらに `e` を選ぶ → `find('e')` が `-1` を返す。
3. `pop(-1)` が末尾の `f` を取り出す。
4. `item == 'f'` となりフラグが表示される。

> `e` は末尾に一番近いため最少手数。

## 用語補足
- **nc (netcat)**: サーバに接続して通信するツール。
- **find**: 文字列内の位置を返すメソッド。無ければ `-1`。
- **pop**: リストから要素を取り出して削除。負の添字は末尾から数える。

## 補足: リスト変換後の中身

`list(self.stock)` で変換した最初の状態:

- 全部で **201要素**（a30 + b60 + c20 + d50 + e40 + f1）
- 1文字ずつバラバラの要素になる
- 順番は `['a','a',...,'e','e','f']`
- **一番最後（位置200）が `'f'`**

```
['a', 'a', ... (a が30個),
 'b', 'b', ... (b が60個),
 'c', 'c', ... (c が20個),
 'd', 'd', ... (d が50個),
 'e', 'e', ... (e が40個),
 'f']
```

位置は0から数えるので末尾は位置200。`pop(-1)` はこの `'f'` を消す(取り出す)。
